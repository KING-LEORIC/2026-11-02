## 구현할 부분

**D06**: SmallCNN·Head·Partial 세 경로를 실행한다. 힌트: [('small',16,1),('head',16,1),('partial',16,1)].

## 입력·출력

입력: `../day11_image_classification/data/`의 train/valid 또는 코드에 주어진 정상 Tensor. test는 사용하지 않습니다. 출력은 이 실습의 `outputs/`입니다. 비교용 결과는 `expected/`에서 확인합니다.

실제 ImageNet 가중치 필요. 현재 제작 환경에서 다운로드가 막혀 실제 전이학습 결과는 미검증입니다. `expected/README.md`에 구분했으며 성능 수치는 기입하지 않았습니다.

## 완료 기준·기록

코드와 출력 파일을 대조하고 바꾼 조건 1개·고정한 조건 2개를 설명하세요. 원래 입력 shape와 처리 후 shape, 결과를 일반화하기 어려운 이유를 한 문장씩 기록합니다.

- 바꾼 조건:
        모델 구조 및 전이학습 전략 : 무작위 초기화된 SmallCNN / 백본을 고정한 Head / 백본 일부와 분류기를 미세조정하는 Partial
        입력 이미지 크기 : 32×32, 224×224 
        학습률 설정 : small 0.01 / head 0.001 / partial 레이어별 차등 적용
- 고정 조건: 
        무작위 난수 시드(torch.manual_seed(42))
        총 학습 에폭 수(epochs = 1)
        옵티마이저 종류(AdamW 및 가중치 감쇠 0.0001)
- 관찰과 한계: 사전학습 가중치를 활용한 Head와 Partial 모델이 단 1회의 에폭 학습만으로도 매우 높은 정확도와 낮은 손실을 기록했으나, 모델 아키텍처, 해상도, 배치 크기, 학습률 등의 여러 변수가 동시에 달라져 순수한 전이학습 효과만으로 일반화하기는 어려움

## 결론
ImageNet 사전학습 가중치를 활용한 전이학습 모델(Head/Partial)은 무작위 초기화된 모델(Small)에 비해 초기 수렴 속도와 성능 면에서 압도적인 우위를 보였으며, 특히 상위 레이어의 가중치를 함께 미세조정한 Partial 방식이 가장 정교한 최적화 결과를 달성함을 확인
